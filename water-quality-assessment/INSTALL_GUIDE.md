## 🚀 ขั้นตอนที่ 2: การติดตั้ง

### 2.1 แตกไฟล์โปรเจค
1. แตกไฟล์ `water-quality-assessment.zip` ที่ดาวน์โหลดมา
2. วางโฟลเดอร์ไว้ที่ตำแหน่งที่สะดวก เช่น:
   ```
   C:\Users\YourName\Documents\water-quality-assessment
   ```

### 2.2 เปิด Command Prompt
1. กด `Windows + R`
2. พิมพ์ `cmd` แล้วกด Enter
3. เข้าไปในโฟลเดอร์โปรเจค:
   ```bash
   cd C:\Users\YourName\Documents\water-quality-assessment
   ```

### 2.3 สร้าง Virtual Environment (แนะนำให้ทำ)
```bash
python -m venv venv
```

**รอสักครู่** จนกว่าจะเสร็จ (ประมาณ 30 วินาที)

### 2.4 เปิดใช้งาน Virtual Environment
**สำหรับ Windows:**
```bash
venv\Scripts\activate
```

**ถ้าสำเร็จ** จะเห็น `(venv)` ด้านหน้าบรรทัดคำสั่ง:
```
(venv) C:\Users\YourName\Documents\water-quality-assessment>
```

### 2.5 ติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

**รอสักครู่** จนกว่าจะติดตั้งเสร็จ (ประมาณ 2-3 นาที)

### 2.6 เริ่มต้นฐานข้อมูล
```bash
python init_db.py
```

**ผลลัพธ์ที่ควรเห็น:**

### 4.1 ทดสอบกรอกข้อมูลด้วยมือ
1. คลิกเมนู **"กรอกข้อมูล"**
2. กรอกข้อมูลตัวอย่าง:
   - **วันที่:** (จะตั้งค่าอัตโนมัติ)
   - **สถานที่:** โรงพยาบาล A
   - **pH:** 7.5
   - **BOD:** 15
   - **COD:** 100
   - **TSS:** 25
   - **TDS:** 800
   - **O&G:** 18
   - **TKN:** 30
   - **Sulfide:** 0
   - **TCB:** 4000
   - **FCB:** 800
   - **Cl₂:** 0.8
3. คลิก **"บันทึกและประเมินผล"**
4. ดูผลการประเมิน

### 4.2 ทดสอบอัปโหลด Excel
1. คลิกเมนู **"อัปโหลด Excel"**
2. เลือกไฟล์ **`sample_data.xlsx`** ที่มีในโฟลเดอร์โปรเจค
3. คลิก **"อัปโหลดและประเมินผล"**
4. ระบบจะประมวลผลและบันทึกข้อมูลทั้งหมด

### 4.3 ดู Dashboard
1. คลิกเมนู **"Dashboard"**
2. จะเห็น:
   - สถิติโดยรวม (ทั้งหมด, ผ่าน, ใกล้เกณฑ์, ไม่ผ่าน)
   - กราฟแนวโน้ม 30 วันล่าสุด
   - ตารางข้อมูล 10 รายการล่าสุด

### 4.4 ดูประวัติ
1. คลิกเมนู **"ประวัติ"**
2. จะเห็นรายการข้อมูลทั้งหมด
3. คลิก **"ดูผล"** เพื่อดูรายละเอียด

## ❗ การแก้ปัญหาที่พบบ่อย

### ปัญหา 1: ไม่สามารถเปิดใช้งาน Virtual Environment
**วิธีแก้:**
```bash
# ใช้คำสั่งนี้แทน
venv\Scripts\activate.bat
```

หรือถ้ายังไม่ได้ ให้ข้ามขั้นตอน Virtual Environment ไปเลย และติดตั้ง library โดยตรง:
```bash
pip install -r requirements.txt
```

### ปัญหา 2: Error "No module named 'flask'"
**สาเหตุ:** ยังไม่ได้ติดตั้ง dependencies

**วิธีแก้:**
```bash
pip install -r requirements.txt
```

### ปัญหา 3: Port 5000 ถูกใช้งานแล้ว
**สาเหตุ:** โปรแกรมอื่นใช้ port 5000 อยู่

**วิธีแก้:**
1. เปิดไฟล์ `app.py`
2. ไปที่บรรทัดสุดท้าย
3. เปลี่ยนจาก:
   ```python
   app.run(debug=True, host='0.0.0.0', port=5000)
   ```
   เป็น:
   ```python
   app.run(debug=True, host='0.0.0.0', port=5001)
   ```
4. บันทึกไฟล์
5. เปิดเว็บที่: `http://localhost:5001`

### ปัญหา 4: ไม่สามารถอัปโหลด Excel ได้
**สาเหตุ:** รูปแบบไฟล์ Excel ไม่ถูกต้อง

**วิธีแก้:**
- ตรวจสอบว่ามีคอลัมน์ครบตามที่กำหนด
- แถวแรกต้องเป็นชื่อคอลัมน์
- ข้อมูลเริ่มจากแถวที่ 2

### ปัญหา 5: หน้าเว็บไม่แสดงผล
**วิธีแก้:**
1. ปิดเซิร์ฟเวอร์ (กด Ctrl+C ใน Command Prompt)
2. รันใหม่:
   ```bash
   python app.py
   ```
3. Refresh หน้าเว็บ (กด F5)
