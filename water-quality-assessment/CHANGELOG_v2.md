# 📝 Changelog — เวอร์ชัน 2.0 (พฤษภาคม 2569)

## 🎯 สรุปการเปลี่ยนแปลงหลัก

ระบบประเมินคุณภาพน้ำได้รับการปรับปรุงตาม **ความเห็นของอาจารย์ปุ๊ (1 พ.ค. 2569)** เพื่อให้สอดคล้องกับ
**ประกาศกระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม เรื่อง กำหนดมาตรฐานควบคุมการระบายน้ำทิ้ง
จากอาคารบางประเภทและบางขนาด พ.ศ. 2567** (ราชกิจจานุเบกษา 27 ส.ค. 2567)

มีการเปลี่ยนแปลงสำคัญ 3 ประการ:

### 1. ✨ รองรับประเภทอาคาร 4 ประเภท (ก / ข / ค / ง)

- เพิ่ม dropdown "ประเภทอาคาร" ในหน้า **เพิ่มข้อมูล**, **อัปโหลด**, **แก้ไข**
- ค่าเริ่มต้น: **ก** (เข้มงวดที่สุด — สำหรับโรงพยาบาลขนาด ≥ 30 เตียง)
- ระบบจะคำนวณ Fuzzy Logic แยกกันตามประเภทอาคาร

### 2. 🧮 ค่ามาตรฐานต่อประเภทอาคาร

| Parameter | ก | ข | ค | ง |
|-----------|---|---|---|---|
| pH | 5.0–9.0 | 5.0–9.0 | 5.0–9.0 | 5.0–9.0 |
| BOD (mg/L) | ≤ 20 | ≤ 30 | ≤ 40 | ≤ 50 |
| COD (mg/L) | ≤ 120 | ≤ 120 | ≤ 120 | ≤ 120 |
| TSS (mg/L) | ≤ 30 | ≤ 40 | ≤ 50 | ≤ 60 |
| TDS (mg/L) | ≤ 1,000 | ≤ 1,000 | ≤ 1,300 | **ไม่กำหนด** |
| O&G (mg/L) | ≤ 20 | ≤ 20 | ≤ 20 | ≤ 20 |
| TKN (mg/L) | ≤ 35 | ≤ 35 | ≤ 40 | **ไม่กำหนด** |
| Sulfide (mg/L) | ≤ 1.0 | ≤ 1.0 | ≤ 1.0 | **ไม่กำหนด** |
| TCB (MPN/100mL) | ≤ 5,000 | ≤ 5,000 | **ไม่กำหนด** | **ไม่กำหนด** |
| FCB (MPN/100mL) | ≤ 1,000 | ≤ 1,000 | **ไม่กำหนด** | **ไม่กำหนด** |
| Cl₂ (mg/L) | 0.2–1.0 | 0.2–1.0 | **ไม่กำหนด** | **ไม่กำหนด** |

ขนาดโรงพยาบาล (ตามคู่มือ ทส./ส.พญ.):
- **ก**: ≥ 30 เตียง
- **ข**: 10–29 เตียง
- **ค**: < 10 เตียง / สถานพยาบาลขนาดเล็ก
- **ง**: ขนาดเล็กที่สุด / กลุ่มอื่นที่กฎหมายระบุ

> **หมายเหตุ:** พารามิเตอร์ที่ "ไม่กำหนด" จะไม่มีผลต่อคะแนน Fuzzy
> (ค่ามาตรฐานเสมือนเป็น `≤ ∞` → membership = "ปลอดภัย" ตลอด)
> และจะแสดงสถานะ "ไม่กำหนด" ในหน้าผลและไฟล์ Excel

### 3. 📊 ปรับช่วงคะแนน WQI ใหม่ (มาตรฐาน Brown 1970 / NSF / RID)

| Score | ระดับ | ความหมาย | สถานะระบบ |
|-------|-------|----------|-----------|
| 80–100 | Excellent | ดีเยี่ยม | **Pass** |
| 60–79 | Good | ดี | **Pass** |
| 40–59 | Fair | ปานกลาง | **Near Limit** (เฝ้าระวัง) |
| 20–39 | Poor | แย่ | **Fail** |
| 0–19 | Very Poor | แย่มาก | **Fail** |

**เปลี่ยนแปลงจากเดิม:** เกณฑ์ Pass เลื่อนจาก 70 เป็น 60 และ Near Limit จาก 50 เป็น 40
เพื่อให้สอดคล้องกับ Water Quality Index มาตรฐานสากล

แหล่งอ้างอิง:
- Brown, R.M. et al. (1970) — National Sanitation Foundation Water Quality Index
- กรมชลประทาน (qwater.rid.go.th) — เกณฑ์คุณภาพน้ำผิวดิน 5 ระดับ
- Sutadian, A.D. et al. (2016) — Development of river water quality indices

## 🔄 การ Migration อัตโนมัติ

เมื่อรันแอปครั้งแรกหลังอัปเกรด ระบบจะตรวจสอบและเพิ่ม column `building_type` ใน
ตาราง `water_quality_data` โดยอัตโนมัติ ไม่ต้องลบฐานข้อมูล:

```
✅ Migration: เพิ่ม column 'building_type' ในตาราง water_quality_data สำเร็จ
```

ข้อมูลเก่าจะได้ค่า default = **ก** (อาคารประเภทเข้มงวดที่สุด)
ผู้ใช้สามารถแก้ไขผ่านหน้า "แก้ไข" เพื่อกำหนดประเภทที่ถูกต้องและให้ระบบประเมินใหม่

## 🔐 ผลกระทบกับข้อมูลเก่า

- ข้อมูลเก่าทั้งหมดจะได้ `building_type = 'ก'` โดยอัตโนมัติ
- คะแนนเก่าใน `EvaluationResult` จะ **ไม่ถูกคำนวณใหม่** อัตโนมัติ
- ถ้าต้องการคำนวณใหม่: เข้าหน้า **แก้ไข** → กดบันทึก (ไม่ต้องเปลี่ยนค่าใดๆ)
  ระบบจะ re-evaluate ด้วย fuzzy v2.0 + เกณฑ์ WQI ใหม่
- หรือใช้ฟังก์ชัน `_re_evaluate_all_rows()` (สำหรับ admin)
